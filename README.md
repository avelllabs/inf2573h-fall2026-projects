# INF2573H Fall 2026: student projects

Final projects from **INF2573H, Designing Human Agency in AI Systems**, a graduate studio at the
University of Toronto's Faculty of Information (Fall 2026), taught by Majid Behboudi and Mazi Javidiani.

Each team built one AI product over twelve weeks, around one rule: people must be able to see,
question and override what the system proposes.

## Projects

Projects are posted here after Final Demo Day (December 3, 2026). Each one lives in its own folder
with its own README: what the product is, how to run it, and who built it.

## What is in each folder

- `README.md`: the project page, written by the team (see [`TEMPLATE-README.md`](TEMPLATE-README.md))
- the working code, with a `.env.example` listing the environment variables it needs (names only)
- `dossier/`: the team's weekly work, assembled

No API keys or other secrets are published here. To run a project you supply your own keys.
